# Bell-State-Entanglement-Simulation

The Bell state creates perfect correlation between 2 qubits. 

Create uncertainty in 1 qubit with H gate.

Link another qubit to it & trigger entanglement with CNOT gate.

Since the states |01⟩ and |10⟩ are not part of the Bell state, they have 0% probability of being measured. 

The system now exists only as a superposition of |00⟩ and |11⟩ only. 

This means both qubits now share one quantum state;
so measuring one qubit instantly determines the state of the other.
