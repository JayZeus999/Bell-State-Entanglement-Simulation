# Bell-State-Entanglement-Simulation

The Bell state creates perfect correlation between both qubits. 

The system exists as a superposition of |00⟩ and |11⟩ only. 

Since the states |01⟩ and |10⟩ are not part of the Bell state, they have 0% probability of being measured. 

Measuring one qubit instantly determines the state of the other.


Create uncertainty in one qubit.
↓
Link another qubit to it.
↓
Both now share one quantum state.
↓
Measurement of one determines both.
